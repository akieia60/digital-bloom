## 📱 **PLATFORM-SPECIFIC TIPS**

### Runway ML:
- Keep prompts under 200 characters for best results
- Use "slow motion" or "time-lapse" for speed control
- Mention "4K" for higher quality

### Pika Labs:
- Start with subject, then describe motion
- Use "-motion 3" parameter for smooth movement
- Keep descriptions clear and specific

### Luma AI:
- Very detailed prompts work best
- Mention camera movement explicitly
- Include lighting details

### Leonardo.ai:
- Upload reference image first
- Use Motion feature
- Keep prompts focused on movement

---

## ✨ **PRO TIPS**

1. **Be Specific:** "12 red roses" vs "roses"
2. **Describe Motion:** "slow 360 rotation" vs "moving"
3. **Mention Lighting:** Always include lighting style
4. **Set the Mood:** Romantic, elegant, cheerful, etc.
5. **Quality Keywords:** 4K, professional, cinematic, HD
6. **Background:** White, marble, wood, garden, etc.
7. **Camera Angle:** From above, eye-level, side view
8. **Time of Day:** Morning light, golden hour, soft daylight
