## 🆘 **Need Help?**

**Video won't play?**
- Check file is .mp4 format
- Check file size (keep under 10MB)
- Check file path is correct

**Too slow to load?**
- Compress video (use HandBrake - free)
- Target 5-10 seconds max
- Keep file size under 5MB

**Wrong size/format?**
- Use online converter (cloudconvert.com)
- Convert to MP4
- Set to 720p or 1080p
