## 4. Schema Drift: `experience_credit_ledger`

### Migration-defined schema (`supabase/migrations/004_experience_credits.sql`)
```sql
CREATE TABLE experience_credit_ledger (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  credit_id UUID REFERENCES experience_credits(id),
  delta_cents INTEGER NOT NULL,
  reason TEXT NOT NULL,    -- CHECK IN ('purchase','redemption','void','adjustment')
  related_order_id TEXT,
  created_at TIMESTAMP DEFAULT NOW()
);
```

### Actual writes in code (WRONG COLUMNS)

**`api/stripe/webhook.js` line 86 (credit purchase):**
```js
{ credit_id, type: 'purchase', amount_cents, description: '...' }
// ❌ 'type' doesn't exist — should be 'reason'
// ❌ 'amount_cents' doesn't exist — should be 'delta_cents'
// ❌ 'description' doesn't exist — should be omitted
```

**`api/stripe/webhook.js` line 127 (reservation capture):**
```js
{ credit_id, type: 'redemption', amount_cents: -N, description: '...', stripe_session_id }
// ❌ Same wrong columns + 'stripe_session_id' doesn't exist
```

**`api/create-checkout-session.js` line 79 (free checkout):**
```js

```

**`src/lib/credits.js` line 57, 154, 192** — SELECT only, no schema issue

### Resolution
All writes must use: `{ credit_id, delta_cents, reason, related_order_id }`

## 6. Supabase Client Security Issues

### `api/create-checkout-session.js` (line 7-8)
```js
const supabase = createClient(
  process.env.SUPABASE_URL || process.env.VITE_SUPABASE_URL,
  process.env.SUPABASE_SERVICE_ROLE_KEY || process.env.VITE_SUPABASE_ANON_KEY
);
```
- ⚠️ Falls back to `VITE_SUPABASE_ANON_KEY` if service role key is missing
- This means server-side code could run with anon (public) key, which is less privileged and may silently fail on RLS-protected writes

### `api/stripe/webhook.js` (line 15-17)
```js
const supabase = createClient(
  process.env.VITE_SUPABASE_URL,       // ← Uses VITE_ prefixed var
  process.env.SUPABASE_SERVICE_ROLE_KEY  // ← Correct key, but URL uses VITE_ prefix
);
```
- ⚠️ Uses `VITE_SUPABASE_URL` directly instead of `SUPABASE_URL`

### Other API routes (credits/, create-credit-checkout)
- ✅ Use `process.env.SUPABASE_URL` and `process.env.SUPABASE_SERVICE_ROLE_KEY` correctly
