These are Gamble's handwritten visual references for the Digital Bloom website/storefront customization and delivery flow.

## Purpose

These sketches should be treated as stakeholder product-direction artifacts for the **main Digital Bloom website**, not the Prompt Engine / Command Center.

They reinforce the desired UX:
- persistent bloom preview
- step-by-step customization
- visible To / From / message personalization
- frame/border selection
- decorative effect selection
- final review before payment
- visible anti-copy protection in delivered output
