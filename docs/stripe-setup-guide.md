## Option A — Automated (Recommended)

### Prerequisites
- Node.js 18+ installed locally
- Your `.env` file with `STRIPE_SECRET_KEY=sk_test_...`

### Steps

```bash
# 1. Install dependencies (if not already done)
npm install

# 2. Run the setup script
node scripts/setup-stripe-products.js
```

The script will:
1. Create 4 products in your Stripe test account
2. Create a one-time price for each product
3. Print all IDs to the terminal
4. Save results to `stripe-product-ids.json` (gitignored)

Copy the printed env vars into your `.env` file and your **Vercel project settings**.

## Option B — One-Time API Endpoint

If you cannot run Node locally, deploy the app first and then call:

```bash
curl -X POST https://YOUR_VERCEL_URL/api/setup/create-products \
  -H "Content-Type: application/json" \
  -d '{"setup_secret": "YOUR_SETUP_SECRET"}'
```

**Before calling this endpoint:**
1. Set `SETUP_SECRET=some-random-string` in your Vercel environment variables
2. Deploy the app
3. Call the endpoint once
4. Copy the returned `env_vars_block` into Vercel environment variables
5. Redeploy

**After calling this endpoint, delete or disable `/api/setup/create-products.js`.**

## Apple Pay / Google Pay Status

Stripe Checkout **automatically enables Apple Pay and Google Pay** when:
1. Your site is served over HTTPS (Vercel handles this automatically)
2. The customer's browser/device supports it
3. The customer has a card saved in their Apple Wallet or Google Pay

**No extra configuration is required.** Stripe Checkout detects the payment method
and shows the Apple Pay / Google Pay button automatically.

To verify in your Stripe Dashboard:
1. Go to **Settings → Payment methods**
2. Confirm "Apple Pay" and "Google Pay" are listed as active
